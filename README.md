# Игры и игровые плитки PLITAP

Здесь мы будем придумывать игру или игры и игровые плитки на основе PLITAP. Чёткой концепции пока нет — мы готовы рассмотреть любые предложения.

Наша цель — максимально раскрыть возможности протокола: геопоиск, передачу плиток между участниками, коллекционирование и объединение плиток для усиления. Также рассматриваем возможные бои и завоевание других плиток.

Предлагайте свои идеи — от отдельной плитки или игровой механики до целого игрового мира.
