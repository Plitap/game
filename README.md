# Игра на основе PLITAP

Здесь мы вместе придумываем самостоятельную игру и игровые плитки на основе PLITAP. Окончательной концепции пока нет — мы открыты любым предложениям.

Хотим максимально раскрыть возможности протокола: геопоиск, передачу плиток между участниками, коллекционирование и объединение для усиления. Также рассматриваем бои и завоевание плиток.

Предлагайте свои идеи — от отдельной плитки или игровой механики до целого игрового мира.

[Обсудить игру и предложить идею](https://github.com/Plitap/game/discussions)
